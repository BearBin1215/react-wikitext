# Syntax Support

This page lists what the default pipeline does with common constructs. **Render** means structured DOM output; **placeholder** means the position is kept but nothing is evaluated; **degrade** means a source card (a placeholder showing the original source text) plus a diagnostic; **blocked** means dangerous content is dropped with a readable hint; **ignore** means it never reaches the body.

With `/expand`, resolvers, `handlers`, or component overrides, output changes. Refer to the dedicated pages for details.

## Text and blocks

| Construct                         | Status | Default output                         | Notes                                                   |
| --------------------------------- | ------ | -------------------------------------- | ------------------------------------------------------- |
| Paragraphs                        | Render | `<p class="wikitext-paragraph">`       | Two or more blank lines split; single newlines collapse |
| `'''bold'''`, `''italic''`        | Render | `<b>`, `<i>`                           | Both produce `<i><b>…</b></i>`                          |
| `== Heading ==`, source `h1`–`h6` | Render | `<h1>`–`<h6 class="wikitext-heading">` | Participates in anchors and the TOC                     |
| `----`                            | Render | `<hr class="wikitext-hr">`             |                                                         |
| Leading spaces                    | Render | Plain text                             | No preformatted semantics                               |
| `<!-- comment -->`                | Ignore | No output                              |                                                         |
| `[[Category:…]]`                  | Render | Category footer                        | Not in the body; sort keys are hidden                   |
| `__TOC__`, `__NOTOC__`            | Render | TOC control                            | Only affects the TOC                                    |
| `#REDIRECT` on the first line     | Render | Redirect banner                        | Skips the body; does not load the target                |

## Lists and tables

| Construct                               | Status  | Default output                        | Notes                                                                          |
| --------------------------------------- | ------- | ------------------------------------- | ------------------------------------------------------------------------------ |
| `*`, `#`                                | Render  | Nested `<ul>` / `<ol>`                | Continuation lines join the current item                                       |
| `;`, `:`                                | Render  | `<dl>` / `<dt>` / `<dd>`              | Supports `; term : definition` and compact forms                               |
| `{\| … \|}`                             | Render  | `<table><caption>…</caption><tbody>…` | Cells use `<th>` / `<td>`                                                      |
| Table, row, cell attributes             | Render  | Allowlisted attributes                | `style` keeps a safe subset; event attributes and `id` are dropped             |
| `colspan`, `rowspan`                    | Render  | Logical grid plus filler cells        | Clamped to the table; fillers carry compat classes                             |
| Unmatched nested wikitext table markers | Degrade | Source card                           | The whole table degrades; matched nested tables and nested HTML `<table>` work |
| `data-*` on tables                      | Render  | Safe values kept                      | Reserved names such as `data-node-id` are rejected                             |

## Links and media

| Construct                     | Status      | Default output                               | Notes                                                                  |
| ----------------------------- | ----------- | -------------------------------------------- | ---------------------------------------------------------------------- |
| `[[Page]]`                    | Render      | Non-navigable `<span class="wikitext-link">` | Becomes `<a>` when `resolveLink` returns `href`                        |
| `[[Page\|label]]`             | Render      | Same, label is `label`                       | Namespace prefixes follow the parse result                             |
| `[https://example.com label]` | Render      | `<a>` with `rel` and `target`                | Only `http:`, `https:`, `mailto:`                                      |
| Bare `https://…`              | Render      | `<a>` labelled with the URL                  |                                                                        |
| `[https://example.com]`       | Render      | `<a>` labelled `[N]`                         | Numbering is independent of references                                 |
| `[[File:…]]`                  | Placeholder | `<span>` or `<figure>` placeholder           | `<img>` only after `resolveImage`                                      |
| `<gallery>`                   | Placeholder | Placeholder set of file labels               | Images through `resolveImage`; otherwise labels (no images by default) |
| `<math>`                      | Placeholder | `<code>` formula source placeholder          | No KaTeX                                                               |
| `<imagemap>`                  | Degrade     | Block-level source card                      | No clickable hotspots                                                  |

## Templates and functions

| Construct                                      | Status      | Default output                                        | Notes                                                         |
| ---------------------------------------------- | ----------- | ----------------------------------------------------- | ------------------------------------------------------------- |
| `{{Template\|…}}`                              | Placeholder | `<details class="wikitext-template">` or inline badge | Lists arguments; text comes from `labels.templateNotExpanded` |
| Parser function `{{#if:…}}`                    | Placeholder | Placeholder structure                                 | Explicitly marked as not evaluated                            |
| Argument `{{{name\|default}}}`                 | Placeholder | Name and default value                                |                                                               |
| Templates and functions supported by `/expand` | Render      | Expanded source is reparsed                           | Calls kept after a failure still render as placeholders       |
| `#invoke`, Lua, `subst`                        | Placeholder | Source preserved                                      | Not executed; a diagnostic is recorded                        |

Magic words inside templates, functions, and arguments do not affect TOC or category detection.

## HTML and extension tags

| Construct                                                 | Status  | Default output                                               | Notes                                                                                                          |
| --------------------------------------------------------- | ------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| Inline HTML (`b`, `i`, `u`, `span`, `code`, …)            | Render  | Corresponding elements                                       | Attributes are allowlisted                                                                                     |
| Block-level HTML (`div`, `p`, `blockquote`, …)            | Render  | Corresponding elements                                       | May wrap headings; TOC position follows its block                                                              |
| Void elements (`br`, `wbr`, `hr`)                         | Render  | Corresponding elements                                       |                                                                                                                |
| `meta`, `link`                                            | Ignore  | No output                                                    |                                                                                                                |
| `script`, `style`, `iframe`, form controls, `svg`         | Blocked | Escaped text, or a readable hint when blocked                | The default config does not parse these tags, so source stays text; if configured as HTML, the pair is dropped |
| Unknown but not dangerous tags                            | Degrade | Source card                                                  | Not rendered as real elements                                                                                  |
| `<nowiki>`                                                | Render  | Plain text                                                   | Links and templates are not parsed                                                                             |
| `<pre>`                                                   | Render  | Whitespace preserved                                         |                                                                                                                |
| `<ref>`                                                   | Render  | `<sup class="reference wikitext-ref">` plus grouped endnotes | Named references are reused; `group` groups; duplicates produce diagnostics                                    |
| `<references>`                                            | Render  | Reference-section position marker                            | The matching group section is moved here; groups without markers stay at the end                               |
| `<syntaxhighlight>`                                       | Render  | `<pre><code class="language-*">` source                      | Emits a language class; no syntax highlighting                                                                 |
| `<poem>`                                                  | Render  | `<div class="wikitext-poem">` with `<p>` stanzas             | Blank lines split stanzas; single line breaks use `<br>`                                                       |
| `templatestyles`, `chem`, `score`, `timeline`, `mapframe` | Degrade | Block-level source card                                      | No stylesheet, formula, score, timeline, or map rendering                                                      |
| Other supported extensions                                | Render  | Handled per tag                                              | `semanticComponents.extension` can override                                                                    |
| Other unsupported extension tags                          | Degrade | Source card                                                  | Block-level when they occupy their own line                                                                    |

## Page-level structure

| Structure              | Behavior                                                                                          |
| ---------------------- | ------------------------------------------------------------------------------------------------- |
| Table of contents      | `toc` adjusts the threshold; `__TOC__` sets the position; `__FORCETOC__` forces; `__NOTOC__` wins |
| Reference section      | After the body and before categories by default; `<references/>` sets a group position            |
| Categories             | Collected into `div#catlinks.catlinks.wikitext-categories` at the end                             |
| Redirect               | First-line `#REDIRECT` renders a banner and skips the body                                        |
| Unknown semantic nodes | Source card plus a diagnostic; the page keeps rendering                                           |

## Combined example

The source below configures no resolvers and covers text, lists, a table, a reference, the default placeholders, a blocked address, and a degraded structure:

```tsx preview
import { Wikitext } from "react-wikitext";
import "react-wikitext/styles.css";

const source = `== Text and lists ==
'''Bold''', ''italic'', and an [[internal link|internal link]] keep their structure.

* First item
* Second item

== Table and reference ==
{| class="wikitable"
|-
! Column A !! Column B
|-
| Cell || Content<ref>Example reference</ref>
|}

{{Infobox|title=Template placeholder}}
[[File:Example.png|thumb|File placeholder]]

[javascript:alert(1) blocked address]

<chem>Example formula</chem>`;

export default function Demo() {
  return <Wikitext source={source} lang="en" />;
}
```

Use the tables to look up a construct; use the example to check the overall output.

## Verifying behavior

1. Inspect `snapshot.diagnostics` for `stage` and `code`.
2. Use `flattenNodes` from `/ast` to inspect the semantic tree and compare it with the prepared HAST.
3. Use `labels` to distinguish "not evaluated", "blocked", and "unknown structure".
4. This page describes behavior under the default configuration; after upgrading, rely on actual diagnostics and rendering.

See [Rendering behavior](./rendering.mdx) for details and rationale, and [Security model](./security.mdx) for blocking rules.
