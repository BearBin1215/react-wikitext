# Expansion `/expand`

```ts
import {
  createWikitextCompiler,
  createTemplateTableProvider,
  WikitextExpandError,
} from "react-wikitext/expand";
```

`/expand` provides a reusable compiler: template expansion runs in a source-aware task graph, caches belong to the compiler instance, and output, diagnostics and DOM lookup all share one source graph. It loads neither a parser nor React; the host injects `parser`.

The compiler executes a supported pure-wikitext subset: supported parser functions and templates. Unsupported functions, Lua and modifiers are preserved verbatim with `failureMode: "preserve"` and the compilation is `partial`.

## Basic usage

```ts
const provider = createTemplateTableProvider({
  key: "offline:demo",
  revision: "templates-v1",
  templates: { "Template:Echo": "{{{1}}}" },
});

const compiler = createWikitextCompiler({ parser, provider });

const compilation = await compiler.compile(
  { key: "page:demo", revision: "edit-42", text: source },
  { pageName: "Demo", signal, failureMode: "preserve" },
);
const snapshot = prepareWikitext(compilation.snapshot);
```

```ts
interface WikitextCompiler {
  readonly parser: WikitextParser;
  readonly providerKey: string;
  compile(input: WikitextInput, options?: WikitextCompileCallOptions): Promise<WikitextCompilation>;
  invalidate(): void;
  clearCache(): void;
  getStats(): WikitextCompilerStats;
  dispose(): Promise<void>;
}
```

The instance configuration is fixed; changing the parser or provider requires a new instance.

## Options

```ts
interface WikitextCompilerOptions {
  parser: WikitextParser;
  provider: WikitextTemplateProvider;
  cache?: { maxEntries?: number; maxBytes?: number };
  fetch?: { concurrency?: number; batchSize?: number };
  limits?: {
    maxSources?: number;
    maxSegments?: number;
    maxInvocations?: number;
    maxDiagnostics?: number;
    maxTemplateBytes?: number;
  };
}

interface WikitextCompileCallOptions {
  pageName?: string;
  signal?: AbortSignal;
  failureMode?: "preserve" | "throw";
  retainSyntax?: boolean;
  parseOptions?: Omit<WikitextParseOptions, "pageName">;
  budget?: WikitextCompileBudget;
  profile?: WikitextStageSink;
}
```

| Option                            | Default                 | Notes                                                                                    |
| --------------------------------- | ----------------------- | ---------------------------------------------------------------------------------------- |
| `failureMode`                     | `preserve`              | Defined recoverable failures keep source text and record diagnostics; `throw` fails fast |
| `budget.maxDepth`                 | `40`                    | Evaluation depth limit, positive integer                                                 |
| `budget.maxInvocations`           | `1000`                  | Evaluated call limit, non-negative safe integer                                          |
| `budget.maxExpandedLength`        | parse `maxSourceLength` | Expanded source length limit                                                             |
| `budget.maxTemplates`             | `5000`                  | Templates read per compilation                                                           |
| `profile`                         | none                    | Stage timing sink (`WikitextStageSink`); omitted means no timing                         |
| `cache.maxEntries` / `maxBytes`   | `500` / `16 MiB`        | Entry and byte bounded LRU                                                               |
| `fetch.concurrency` / `batchSize` | `4` / `50`              | Concurrency cap and `getMany` batch size                                                 |

Original parse failures, hard resource limits, cancellation and incompatible parsers always fail.

## Template provider

```ts
interface WikitextTemplateProvider {
  readonly key: string;
  open(context: WikitextProviderContext): WikitextTemplateSnapshot | Promise<WikitextTemplateSnapshot>;
}

interface WikitextTemplateSnapshot {
  readonly key: string;
  readonly revision: string;
  get(title: string, request: WikitextTemplateRequest):
    | WikitextTemplateSource
    | null
    | undefined
    | Promise<WikitextTemplateSource | null | undefined>;
  getMany?(titles: readonly string[], requests: readonly WikitextTemplateRequest[]):
    | ReadonlyMap<string, WikitextTemplateSource | null>
    | Readonly<Record<string, WikitextTemplateSource | null>>
    | Promise</* as above */>;
  release?(): void | Promise<void>;
}
```

- One compilation uses exactly one snapshot; template edits during an edit session never mix versions.
- A snapshot must return stable content for a title; changed content requires a new `revision`.
- `null` means missing; `undefined` or a wrong type is treated as a fetch failure.
- `createTemplateTableProvider` validates and copies once; update the table by creating a new version.
- Remote providers own auth, redirects, site data, rate limits and I/O; the library never guesses site URLs.
- `release` is called once after success, failure or cancellation; `dispose` never destroys a host provider.

## Compilation result

```ts
type WikitextCompilationStatus = "complete" | "partial" | "fallback";

interface WikitextCompilation {
  readonly schemaVersion: 1;
  readonly status: WikitextCompilationStatus;
  readonly inputSourceId: string;
  readonly outputSourceId: string;
  readonly attemptedSourceId?: string;
  readonly snapshot: WikitextParsedSnapshot;
  readonly dependencies: readonly WikitextCompilationDependency[];
  readonly stats: WikitextCompilationStats;
}
```

- `complete`: every supported and actually evaluated call finished.
- `partial`: preserved calls, unresolved dependencies or visible supported-function errors.
- `fallback`: the final semantic parse failed and the active snapshot uses the original LF source; `attemptedSourceId` points at the abandoned expanded source and attempted output spans are not rewritten.

Diagnostics and the source graph live only on `snapshot`; the outer object describes status, source identities, dependencies and stats.

## Source graph and lookup

```ts
import {
  mapSourceSpan,
  locateRenderedNode,
  findRenderedNodes,
  getSourcePosition,
} from "react-wikitext/ast";

const located = locateRenderedNode(snapshot, nodeId); // projects to the page input by default
const nodes = findRenderedNodes(snapshot, {
  sourceId: snapshot.activeSourceId,
  start: 0,
  end: 10,
});
const position = getSourcePosition(snapshot.graph, span);
```

- `WikitextMappingMatch.precision` is `exact` or `enclosing-invocation`; multi-hop composition never upgrades precision.
- Every occurrence of a repeated template is returned; when the limit is reached `truncated` is `true`.
- Deleted ranges, generated characters and function results never claim exact mapping.
- Line and column data is derived from the owning source on demand.

## Caching and scheduling

| Cache                   | Key contains                                                                    | Invalidation                                                                                                    |
| ----------------------- | ------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Template fetch result   | provider key, snapshot revision, normalized title                               | revision changes; missing results reused within one revision; transient failures are not cached across compiles |
| Template syntax program | parser identity, budgets, page context, normalized content, preprocessing rules | bounded LRU                                                                                                     |
| Page syntax compilation | parser identity, input content, budgets                                         | unchanged text is reused                                                                                        |

Evaluation advances in deterministic rounds: pure computation runs first, uncompiled templates are recorded as demands and deferred, then the scheduler deduplicates by provider snapshot, fetches in batches and commits results at fixed task addresses. Output, call status and diagnostics therefore do not depend on network completion order; `concurrency: 1` and larger values produce identical results.

Concurrent compiles share unfinished fetches for the same provider snapshot. Cancelling one compile only removes that subscriber; the underlying request is aborted after the last subscriber leaves.

## Resource limits

Source counts, segment counts, invocation records, diagnostics, total template source bytes and expanded text length all have independent caps. Exceeding a hard cap without a complete valid snapshot fails the whole compilation; text is never truncated and ranges are never fabricated.

## Errors

`WikitextExpandError.code` includes `INVALID_EXPAND_OPTIONS`, `INVALID_PROVIDER`, `INCOMPATIBLE_PARSER`, `TEMPLATE_NOT_FOUND`, `TEMPLATE_RESOLVE_FAILED`, `TEMPLATE_PARSE_FAILED`, `TEMPLATE_LOOP`, `UNSUPPORTED_CALL`, `UNRESOLVED_DEPENDENCY`, `EXPANSION_BUDGET_EXCEEDED`, `EXPANSION_TOO_LARGE`, `FINAL_PARSE_FAILED`, `SOURCE_GRAPH_TOO_LARGE`, `ABORTED` and `DISPOSED`.

Errors share the `WikitextSourceSpan` location model with snapshot diagnostics; `location` points at the text source where the failure actually happened.
