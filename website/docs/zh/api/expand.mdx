# 展开 `/expand`

```ts
import {
  createWikitextCompiler,
  createTemplateTableProvider,
  WikitextExpandError,
} from "react-wikitext/expand";
```

`/expand` 提供可复用的编译器：模板展开在带来源信息的任务图中执行，缓存归编译器实例管理，输出、诊断与 DOM 定位共用同一份来源图。它不加载解析器与 React，`parser` 由宿主注入。

编译器只执行已支持的纯 wikitext 子集：受支持的解析器函数与模板；未支持函数、Lua 与 modifier 在 `failureMode: "preserve"` 下原样保留，状态为 `partial`。

## 基本用法

```ts
const provider = createTemplateTableProvider({
  key: "offline:demo",
  revision: "templates-v1",
  templates: { "Template:Echo": "{{{1}}}" },
});

const compiler = createWikitextCompiler({ parser, provider });

const compilation = await compiler.compile(
  { key: "page:demo", revision: "edit-42", text: source },
  { pageName: "Demo", signal, failureMode: "preserve" },
);
const snapshot = prepareWikitext(compilation.snapshot);
```

`createWikitextCompiler` 返回 `WikitextCompiler`；实例配置固定，更换 parser 或 provider 需要创建新实例。

```ts
interface WikitextCompiler {
  readonly parser: WikitextParser;
  readonly providerKey: string;
  compile(input: WikitextInput, options?: WikitextCompileCallOptions): Promise<WikitextCompilation>;
  invalidate(): void;
  clearCache(): void;
  getStats(): WikitextCompilerStats;
  dispose(): Promise<void>;
}
```

## 编译选项

```ts
interface WikitextCompilerOptions {
  parser: WikitextParser;
  provider: WikitextTemplateProvider;
  cache?: { maxEntries?: number; maxBytes?: number };
  fetch?: { concurrency?: number; batchSize?: number };
  limits?: {
    maxSources?: number;
    maxSegments?: number;
    maxInvocations?: number;
    maxDiagnostics?: number;
    maxTemplateBytes?: number;
  };
}

interface WikitextCompileCallOptions {
  pageName?: string;
  signal?: AbortSignal;
  failureMode?: "preserve" | "throw";
  retainSyntax?: boolean;
  parseOptions?: Omit<WikitextParseOptions, "pageName">;
  budget?: WikitextCompileBudget;
  profile?: WikitextStageSink;
}
```

| 选项                              | 默认值                       | 说明                                                   |
| --------------------------------- | ---------------------------- | ------------------------------------------------------ |
| `failureMode`                     | `preserve`                   | 已定义的可恢复失败保留原文并记录诊断；`throw` 直接抛错 |
| `budget.maxDepth`                 | `40`                         | 求值调用栈深度上限，正整数                             |
| `budget.maxInvocations`           | `1000`                       | 实际进入求值的调用次数上限，非负安全整数               |
| `budget.maxExpandedLength`        | 解析预算的 `maxSourceLength` | 展开后源码长度上限                                     |
| `budget.maxTemplates`             | `5000`                       | 单次编译读取的模板数量上限                             |
| `profile`                         | 无                           | 阶段计时接收器 `WikitextStageSink`；省略时不计量       |
| `cache.maxEntries` / `maxBytes`   | `500` / `16 MiB`             | 条目与字节双重 LRU                                     |
| `fetch.concurrency` / `batchSize` | `4` / `50`                   | 并发上限与 `getMany` 批大小                            |

原始解析失败、硬资源上限、取消与不兼容 parser 始终失败，不受 `failureMode` 影响。

## 模板 provider

```ts
interface WikitextTemplateProvider {
  readonly key: string;
  open(context: WikitextProviderContext): WikitextTemplateSnapshot | Promise<WikitextTemplateSnapshot>;
}

interface WikitextTemplateSnapshot {
  readonly key: string;
  readonly revision: string;
  get(title: string, request: WikitextTemplateRequest):
    | WikitextTemplateSource
    | null
    | undefined
    | Promise<WikitextTemplateSource | null | undefined>;
  getMany?(titles: readonly string[], requests: readonly WikitextTemplateRequest[]):
    | ReadonlyMap<string, WikitextTemplateSource | null>
    | Readonly<Record<string, WikitextTemplateSource | null>>
    | Promise</* 同上 */>;
  release?(): void | Promise<void>;
}
```

- 一次编译固定使用同一个快照；编辑期间模板更新不会把两个版本混入一个结果。
- 同一快照对同一标题必须返回稳定内容；内容变化必须更换 `revision`。
- `null` 表示明确不存在；`undefined` 或类型不符按获取失败处理。
- `createTemplateTableProvider` 在构造时校验并复制一次，后续编译复用；更新表要构造新版本。
- 远程 provider 负责鉴权、重定向、站点数据、限流与 I/O；库不猜测站点 URL。
- `release` 在成功、失败与取消后各调用一次；`dispose` 不销毁宿主提供的 provider。

## 编译结果

```ts
type WikitextCompilationStatus = "complete" | "partial" | "fallback";

interface WikitextCompilation {
  readonly schemaVersion: 1;
  readonly status: WikitextCompilationStatus;
  readonly inputSourceId: string;
  readonly outputSourceId: string;
  readonly attemptedSourceId?: string;
  readonly snapshot: WikitextParsedSnapshot;
  readonly dependencies: readonly WikitextCompilationDependency[];
  readonly stats: WikitextCompilationStats;
}
```

- `complete`：受支持且实际求值的调用全部完成。
- `partial`：有保留调用、未解决依赖或受支持函数产生的可见错误结果。
- `fallback`：最终语义解析失败，活动快照使用原始 LF 源码；`attemptedSourceId` 指向被放弃的展开源，尝试展开的输出范围不会被改写。

诊断与来源图只保存在 `snapshot`，外层只描述状态、源码身份、依赖与统计。

## 来源图与定位

`snapshot.graph` 登记输入原文、LF 文本、模板原文、有效正文与展开结果，以及片段关系与调用记录。

```ts
import {
  mapSourceSpan,
  locateRenderedNode,
  findRenderedNodes,
  getSourcePosition,
} from "react-wikitext/ast";

const located = locateRenderedNode(snapshot, nodeId); // 默认投影到页面原文
const nodes = findRenderedNodes(snapshot, {
  sourceId: snapshot.activeSourceId,
  start: 0,
  end: 10,
});
const position = getSourcePosition(snapshot.graph, span);
```

- `WikitextMappingMatch.precision` 为 `exact` 或 `enclosing-invocation`；多阶段组合不会提升精度。
- 重复模板出现位置全部返回，不任选第一个；达到上限时 `truncated` 为 `true`。
- 被删除片段、生成字符与函数转换结果不能冒充精确映射。
- 行列坐标由所属文本源按需计算，不与 span 分别存储。

## 缓存与调度

| 缓存         | 键包含                                                | 失效                                                     |
| ------------ | ----------------------------------------------------- | -------------------------------------------------------- |
| 模板获取结果 | provider 键、快照版本、规范化标题                     | 版本变化失效；缺失在同一版本内复用；瞬态错误不跨编译缓存 |
| 模板语法程序 | parser 身份、预算、页面上下文、归一化内容、预处理规则 | 容量受控，按 LRU 淘汰                                    |
| 页面语法编译 | parser 身份、输入内容、预算                           | 静态或未变文本复用                                       |

求值按确定顺序进行：纯计算先推进，需要未编译模板时记录需求并推迟本轮；调度器按 provider 快照去重、批量获取后按固定任务地址提交，再继续下一轮。因此输出、调用状态与诊断不依赖网络返回顺序，`concurrency: 1` 与更大并发结果相同。

并发编译共享同一 provider 快照的未完成获取任务；取消某次编译只移除该订阅者，全部订阅者取消后才中断底层请求。

## 资源上限

来源数量、片段数量、调用记录、诊断数量、模板源码总量与展开文本长度都有独立上限。超过硬上限且不能生成完整有效快照时整次编译失败，不截断文本或伪造来源。

## 错误

```ts
import { WikitextExpandError } from "react-wikitext/expand";
```

`WikitextExpandError.code` 取值包括 `INVALID_EXPAND_OPTIONS`、`INVALID_PROVIDER`、`INCOMPATIBLE_PARSER`、`TEMPLATE_NOT_FOUND`、`TEMPLATE_RESOLVE_FAILED`、`TEMPLATE_PARSE_FAILED`、`TEMPLATE_LOOP`、`UNSUPPORTED_CALL`、`UNRESOLVED_DEPENDENCY`、`EXPANSION_BUDGET_EXCEEDED`、`EXPANSION_TOO_LARGE`、`FINAL_PARSE_FAILED`、`SOURCE_GRAPH_TOO_LARGE`、`ABORTED`、`DISPOSED`。

错误对象与快照诊断共用 `WikitextSourceSpan` 位置模型；`location` 指向真实失败所在的文本源。

## 与实时预览

`/expand` 只提供编译能力。实时调度使用 [`/preview`](./preview.mdx) 的 `useWikitextPreview`，Worker 执行使用 [`/worker`](./worker.mdx)。
