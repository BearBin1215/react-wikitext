# React 组件

根入口导出源码组件 `Wikitext` 与视图组件；只渲染已准备快照的宿主应使用 [`/view`](./view.mdx)，它不加载解析器。

:::warning 警告
组件只能在客户端组件中运行；根入口的产物顶部带有 `"use client"` 指令。完整边界与 SSR 用法见[服务端与框架](../guide/server-rendering.mdx)。
:::

## Wikitext

```tsx
import { Wikitext } from "react-wikitext";
import "react-wikitext/styles.css";

<Wikitext source={source} lang="zh-CN" />;
```

源码组件在内部完成解析、准备与渲染，只支持同步管线。

### 属性

```ts
interface WikitextProps extends Omit<WikitextViewProps, "snapshot"> {
  source: string;
  parser?: WikitextParser;
  parseOptions?: WikitextParseOptions;
  prepareOptions?: WikitextPrepareOptions;
  onPrepared?: (snapshot: WikitextRenderSnapshot) => void;
  onError?: (error: WikitextError, info: { stage: "parse" | "prepare" }) => void;
  fallback?:
    | React.ReactNode
    | ((error: WikitextError, info: { stage: "parse" | "prepare" }) => React.ReactNode);
}
```

| 属性             | 说明                                                                                                                                                                                         |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `source`         | 待渲染的 wikitext 源码                                                                                                                                                                       |
| `parser`         | 复用已创建的解析器；缺省使用默认配置的共享解析器                                                                                                                                             |
| `parseOptions`   | 解析选项，见 [`/parse`](./parse.mdx)                                                                                                                                                         |
| `prepareOptions` | 准备选项，见 [`/hast`](./prepare.mdx)                                                                                                                                                        |
| `onPrepared`     | 准备成功后回调；读取快照的 `diagnostics`、`headings` 与生效设置                                                                                                                              |
| `onError`        | 解析/准备失败回调；`error` 一定是 `WikitextError`，`info.stage` 区分阶段                                                                                                                     |
| `fallback`       | 失败时渲染的内容；提供后完全接管展示，不再渲染内置错误容器                                                                                                                                   |
| 其余属性         | 与 [`WikitextView`](./view.mdx#wikitextview) 相同，包括 `components`、`semanticComponents`、`lang` / `dir`、`idPrefix`、`className`、`containerProps`、`sourceAttributes` 与 `onRenderError` |

### 行为

- 解析与准备分别用 `useMemo` 缓存，依赖为 `[parser, source, parseOptions]` 与 `[parsed, prepareOptions]`；只改 `prepareOptions` 会复用上一次的解析结果。
- 每次渲染传入新的选项对象会导致对应阶段重新执行；请固定引用。
- 插件与解析回调必须是纯函数；异步插件会抛 `ASYNC_PLUGIN_IN_SYNC_PATH`。
- 导入 `/parse` 会执行上游 IIFE；默认解析器实例在首次解析时懒创建。不需要解析器时使用 `/view`。
- 占位、拦截与降级以诊断形式写入快照，页面仍然渲染成功；用 `onPrepared` 读取这些记录，不要依赖 `onError`。

## 错误处理

```tsx
<Wikitext
  source={source}
  onRenderError={(error, { node }) => {
    reportError(error, { nodeType: node.type, nodeId: node.id });
  }}
/>
```

解析或准备失败时，可以用 `fallback` 接管展示：

```tsx
<Wikitext
  source={source}
  onError={(error, info) => console.error(info.stage, error.code)}
  fallback={<p>内容加载失败</p>}
/>
```

错误边界按顶层 HAST 块隔离，块级失败的显示与 `onRenderError` 见[视图组件](./view.mdx#渲染错误)。解析与准备错误不会进入错误边界，按传入的回调处理：

| 传入                     | 行为                                                          |
| ------------------------ | ------------------------------------------------------------- |
| 无 `onError`、`fallback` | 直接抛给外层错误边界                                          |
| 只有 `onError`           | 显示内置错误容器，文案取 `prepareOptions.labels.renderFailed` |
| 提供 `fallback`          | 由 `fallback` 完全接管；返回 `null` 时不渲染内容              |
