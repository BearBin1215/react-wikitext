# 支持矩阵

本页按“默认管线会怎么处理”列出常见构造。**渲染**表示输出结构化 DOM；**占位**表示保留位置但不求值；**降级**表示把原文放进源码卡片（显示源码文本的占位块）并记录诊断；**拦截**表示丢弃危险内容并给出提示；**忽略**表示不进入正文。

启用了 `/expand`、解析回调、`handlers` 或组件覆盖后，具体输出会变化；细节以对应页面为准。

## 文本与块

| 构造                         | 状态 | 默认输出                               | 说明                                   |
| ---------------------------- | ---- | -------------------------------------- | -------------------------------------- |
| 段落                         | 渲染 | `<p class="wikitext-paragraph">`       | 两个及以上空行分段，单个换行折叠为空格 |
| `'''粗体'''`、`''斜体''`     | 渲染 | `<b>`、`<i>`                           | 同时开启时输出 `<i><b>…</b></i>`       |
| `== 标题 ==`、源码 `h1`–`h6` | 渲染 | `<h1>`–`<h6 class="wikitext-heading">` | 参与锚点与目录                         |
| `----`                       | 渲染 | `<hr class="wikitext-hr">`             |                                        |
| 行首空格                     | 渲染 | 普通文本                               | 不提供预格式化语义                     |
| `<!-- 注释 -->`              | 忽略 | 无输出                                 |                                        |
| `[[Category:…]]`             | 渲染 | 文末分类底栏                           | 不进入正文；排序键不显示               |
| `__TOC__`、`__NOTOC__`       | 渲染 | 目录控制                               | 只影响目录，不产生正文                 |
| 首行 `#REDIRECT`             | 渲染 | 重定向横幅                             | 跳过后续正文，不自动加载目标页         |

## 列表与表格

| 构造                           | 状态 | 默认输出                              | 说明                                                         |
| ------------------------------ | ---- | ------------------------------------- | ------------------------------------------------------------ |
| `*`、`#`                       | 渲染 | 嵌套 `<ul>` / `<ol>`                  | 续行并入当前列表项                                           |
| `;`、`:`                       | 渲染 | `<dl>` / `<dt>` / `<dd>`              | 支持 `; term : definition` 与紧凑写法                        |
| `{\| … \|}`                    | 渲染 | `<table><caption>…</caption><tbody>…` | 单元格使用 `<th>` / `<td>`                                   |
| 表格、行、单元格属性           | 渲染 | 白名单属性                            | `style` 仅保留安全子集；事件属性、`id` 丢弃                  |
| `colspan`、`rowspan`           | 渲染 | 逻辑网格 + 填充单元格                 | 范围限制在表格内；填充单元格带兼容类名                       |
| 标记不配对的 wikitext 嵌套表格 | 降级 | 源码卡片                              | 整表降级；标记配对完整的嵌套表格与 HTML `<table>` 嵌套可渲染 |
| 表格内 `data-*`                | 渲染 | 保留安全值                            | 拒绝库保留的 `data-node-id` 等名称                           |

## 链接与媒体

| 构造                          | 状态 | 默认输出                                  | 说明                                                        |
| ----------------------------- | ---- | ----------------------------------------- | ----------------------------------------------------------- |
| `[[Page]]`                    | 渲染 | 不可导航的 `<span class="wikitext-link">` | `resolveLink` 返回 `href` 时变为 `<a>`                      |
| `[[Page\|label]]`             | 渲染 | 同上，标签为 `label`                      | 命名空间前缀按解析结果展示                                  |
| `[https://example.com label]` | 渲染 | `<a>`，带 `rel` 与 `target`               | 只允许 `http:`、`https:`、`mailto:`                         |
| 裸外链 `https://…`            | 渲染 | `<a>`，标签为 URL                         |                                                             |
| `[https://example.com]`       | 渲染 | `<a>`，标签为 `[N]`                       | 编号独立于引用                                              |
| `[[File:…]]`                  | 占位 | `<span>` 或 `<figure>` 占位               | `resolveImage` 授权后才生成 `<img>`                         |
| `<gallery>`                   | 占位 | 图片标签占位集合                          | `resolveImage` 返回时出图；否则显示文件名（默认不加载图片） |
| `<math>`                      | 占位 | `<code>` 公式源码占位                     | 不引入 KaTeX                                                |
| `<imagemap>`                  | 降级 | 块级源码卡片                              | 不生成可点击热区                                            |

## 模板与函数

| 构造                       | 状态 | 默认输出                                         | 说明                                            |
| -------------------------- | ---- | ------------------------------------------------ | ----------------------------------------------- |
| `{{Template\|…}}`          | 占位 | `<details class="wikitext-template">` 或行内徽标 | 列出参数；文案来自 `labels.templateNotExpanded` |
| 解析器函数 `{{#if:…}}`     | 占位 | 占位结构                                         | 明确标记为未求值                                |
| 参数 `{{{name\|default}}}` | 占位 | 参数名与默认值                                   |                                                 |
| `/expand` 支持的模板与函数 | 渲染 | 展开后的源码重新解析                             | 展开失败保留的调用仍按占位渲染                  |
| `#invoke`、Lua、`subst`    | 占位 | 保留原文                                         | 不执行，并产生诊断                              |

模板、函数与参数中的魔术字不参与目录与分类判断。

## HTML 与扩展标签

| 构造                                                      | 状态 | 默认输出                                            | 说明                                                                     |
| --------------------------------------------------------- | ---- | --------------------------------------------------- | ------------------------------------------------------------------------ |
| 行内 HTML（`b`、`i`、`u`、`span`、`code` 等）             | 渲染 | 对应元素                                            | 属性只保留白名单                                                         |
| 块级 HTML（`div`、`p`、`blockquote` 等）                  | 渲染 | 对应元素                                            | 可以包裹标题，目录位置按其所在块计算                                     |
| 空元素（`br`、`wbr`、`hr`）                               | 渲染 | 对应元素                                            |                                                                          |
| `meta`、`link`                                            | 忽略 | 无输出                                              |                                                                          |
| `script`、`style`、`iframe`、表单控件、`svg`              | 拦截 | 文本转义，或被拦截时的可读提示                      | 默认配置不解析这些标签，源码按纯文本转义；被配置纳入 HTML 解析时整对丢弃 |
| 未知但非危险标签                                          | 降级 | 源码卡片                                            | 不渲染为真实元素                                                         |
| `<nowiki>`                                                | 渲染 | 纯文本                                              | 不解析链接或模板                                                         |
| `<pre>`                                                   | 渲染 | 保留空白                                            |                                                                          |
| `<ref>`                                                   | 渲染 | `<sup class="reference wikitext-ref">` + 分组引用区 | 命名引用复用，`group` 分组；重复定义产生诊断                             |
| `<references>`                                            | 渲染 | 引用区位置标记                                      | 对应分组引用区放到标记处；无标记时仍追加文末                             |
| `<syntaxhighlight>`                                       | 渲染 | `<pre><code class="language-*">` 原文               | 输出语言 class，不接语法高亮                                             |
| `<poem>`                                                  | 渲染 | `<div class="wikitext-poem">` + `<p>` 分节          | 空行分节，段内换行输出 `<br>`                                            |
| `templatestyles`、`chem`、`score`、`timeline`、`mapframe` | 降级 | 块级源码卡片                                        | 不加载样式表、公式、乐谱、时间线或地图                                   |
| 其他受支持的扩展                                          | 渲染 | 按标签处理                                          | `semanticComponents.extension` 可覆盖                                    |
| 其他未专门支持的扩展                                      | 降级 | 源码卡片                                            | 独立成行时按块级展示                                                     |

## 页面级结构

| 结构               | 行为                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------ |
| 目录               | 阈值可通过 `toc` 调整；`__TOC__` 指定位置，`__FORCETOC__` 强制生成，`__NOTOC__` 优先 |
| 引用区             | 默认位于正文之后、分类底栏之前；`<references/>` 可指定分组位置                       |
| 分类               | 汇总到文末 `div#catlinks.catlinks.wikitext-categories`                               |
| 重定向             | 首行 `#REDIRECT` 渲染横幅并跳过正文                                                  |
| 无法识别的语义节点 | 源码卡片 + 诊断，不中断整页                                                          |

## 综合示例

下面的源码没有配置解析回调，覆盖文本、列表、表格、引用、默认占位，以及被拦截的地址和降级结构：

```tsx preview
import { Wikitext } from "react-wikitext";
import "react-wikitext/styles.css";

const source = `== 文本与列表 ==
'''粗体'''、''斜体'' 与 [[未配置路由的链接]] 都会保留结构。

* 第一项
* 第二项

== 表格与引用 ==
{| class="wikitable"
|-
! 列 A !! 列 B
|-
| 单元格 || 内容<ref>示例引用</ref>
|}

{{Infobox|title=模板占位}}
[[File:Example.png|thumb|图片占位]]

[javascript:alert(1) 被拦截的地址]

<chem>示例公式</chem>`;

export default function Demo() {
  return <Wikitext source={source} lang="zh-CN" />;
}
```

表格用于逐项查状态，示例用于确认整体输出。

## 如何确认实际行为

1. 检查 `snapshot.diagnostics` 的 `stage` 与 `code`。
2. 用 `/ast` 的 `flattenNodes` 查看语义树，并与准备结果中的 HAST 对照。
3. 用 `labels` 区分“未求值”“已拦截”“未知结构”等占位文案。
4. 本页描述默认配置下的行为；升级版本后，以实际诊断与渲染结果为准。

行为细节与原因见[渲染行为](./rendering.mdx)；安全相关的拦截规则见[安全模型](./security.mdx)。
